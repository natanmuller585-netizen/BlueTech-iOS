# Instalar ou atualizar o BlueTech no iPhone

O BlueTech para iPhone é instalado por sideload com conta Apple gratuita.
Não é necessário pagar nada.

## Primeira instalação ou atualização

1. Abra o BlueTech. Se aparecer **Nova atualização disponível!**, toque em
   **Atualizar agora**. Se preferir, abra
   https://github.com/natanmuller585-netizen/BlueTech-iOS/releases
2. Na página da versão, baixe `Bluetech-iPhone.ipa`.
3. No computador, feche iTunes/Sideloadly se estiverem abertos.
4. Abra o Sideloadly, escolha o arquivo IPA baixado e confirme o iPhone conectado.
5. Digite sua conta Apple **somente dentro do Sideloadly**.
6. Após terminar, no iPhone: Ajustes > Geral > Gestão de dispositivos >
   confiar na sua conta. Ative o Modo Desenvolvedor se aparecer o aviso.

## Entenda duas coisas diferentes

- **Versão do app**: muda quando uma nova Release é publicada.
- **Assinatura**: com conta gratuita dura 7 dias. Depois disso o app não abre
  e precisa ser reinstalado com o mesmo IPA e a mesma conta.

Atualizar o app não renova a assinatura. Renovar a assinatura não muda a versão.

## Segurança

- O app só aceita links HTTPS deste repositório oficial.
- Se o GitHub estiver fora do ar, o BlueTech continua funcionando normalmente.
- O arquivo baixado não é instalado sozinho; você sempre confirma no Sideloadly.
- O SHA-256 de cada IPA é publicado na Release para conferência externa.
